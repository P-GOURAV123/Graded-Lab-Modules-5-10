# Question 1 - Duplicate Submission Checker

## Objective

This shell script identifies duplicate assignment submissions, backs up only unique files, generates a report showing the number of processed, duplicate and backed-up files, and stores error messages separately.

### Command

```bash
mkdir submissions
```

**Explanation:**
Created a directory named `submissions` to store sample student assignment files. This directory acts as the source folder for duplicate checking.

---


## Linux Commands and Techniques Used

- **md5sum** – Generates a checksum for each file to identify duplicate content.
- **cp** – Copies unique files into the backup directory.
- **mkdir** – Creates the required directories.
- **touch** – Creates empty files.
- **echo** – Writes sample data and generates the report.
- **chmod** – Makes the shell script executable.
- **Output Redirection (>)** – Creates or overwrites files.
- **Append Redirection (>>)** – Appends output without deleting existing content.
- **Error Redirection (2>>)** – Stores error messages in a separate file.
- **Associative Array** – Stores file hashes to efficiently detect duplicates.
